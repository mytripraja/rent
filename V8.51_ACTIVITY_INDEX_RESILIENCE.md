# Rental Manager V8.51 — Activity Feed Index Resilience

## Fix

The property-scoped Activity Log previously combined `where(propertyId == ...)` with `orderBy(timestamp desc)`. Firestore can require a composite index for that query, which could cause the Activity Log to fail in a fresh deployment.

V8.51 changes property-scoped activity loading to:
- filter by `propertyId` in Firestore;
- sort by `timestamp` locally;
- apply the requested limit after sorting.

The unrestricted/admin feed keeps the single-field timestamp ordering query.

## Security

The property filter remains enforced by Firestore rules. This update does not broaden access or weaken the V8.50 property boundary.
