# V8.84 — Rent rejection transaction guard

- Reject now reads and revalidates the payment status inside a Firestore transaction.
- A stale or already-actioned payment cannot be overwritten by a rejection attempt.
- The associated house is verified before the status change.
- Notification and activity-log failures are reported as warnings after the committed rejection, rather than making the UI imply that the rejection itself failed.
- No accounting journal is created for rejected rent.

Validation: JavaScript syntax and ZIP integrity checks. No live Firestore or full production build test was run.
