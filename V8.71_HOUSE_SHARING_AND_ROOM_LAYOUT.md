# V8.71 — House sharing + room layout

## House sharing
- Added Share action to the bulk house-selection bar.
- Owner can choose exactly which fields leave the Rental Manager UI.
- Sensitive tenant fields are off by default.
- Share formats: text, image and PDF.
- If the browser cannot attach a file to the native share sheet, the actual image/PDF is saved instead of silently sharing only text.
- Optional tenant login link points to the normal `/login` page.
- Supports one or multiple selected houses.

## House room layout
House creation/editing now stores:
- bedrooms
- halls
- kitchens
- bathrooms
- dressing rooms

Existing houses remain compatible; missing room counts default to zero (with the UI's normal hall/kitchen/bath defaults when editing).

## Security / Firebase
No new public collection was introduced. House room fields are stored inside the existing property-scoped `houses/{houseId}` document, which is already owner/property-access protected by Firestore rules. The share UI is client-side and only includes fields the owner explicitly selects.
