# V8.83 — Rent approval accounting consistency

- Added an authenticated owner-level API route for rent approval.
- Commits payment approval and the matching Cash / Bank debit + Rental Income credit in one Firestore transaction.
- Uses deterministic ledger document IDs and records paymentId on both journal lines.
- Revalidates linked entries for idempotent retries and rejects inconsistent partial legacy states for manual review.
- Moves the client approval service off direct payment writes and best-effort client journal creation.
- Notification and activity logging remain post-transaction side effects; their failures no longer make a committed approval appear to have failed.

Validation: JavaScript syntax checks and ZIP integrity passed. Full Vite build and live Firestore/concurrency tests were not available/performed.
