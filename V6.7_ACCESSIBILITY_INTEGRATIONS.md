# Rental Manager V6.7 — Accessibility, Mobile & Integrations

## Included in this release
- Vehicle-type icons: cars, two-wheelers and EV slots now use different icons.
- Parking slots can be dragged and repositioned; the coordinates are saved to Firestore.
- Tenant mobile dashboard is split into Home / Rent / Bills / More tools instead of one long page.
- Calendar has a mobile day-list view instead of forcing a tiny 7-column grid.
- Tenant blueprint can fall back to the shared property blueprint and has a smaller mobile canvas.
- First login asks for English/Tamil preference. The choice is saved to the user profile.
- Settings is always reachable from the header. Language, notification center, accessibility and integrations live there.
- Admin can enable/disable tenant features per tenant, including Rent & payment submission.
- Owner Simple/Dad Lite mode updates live when the profile changes; a re-login is no longer required just to pick up appMode/permissions.
- Added animated loading screen and a real 404 page.
- Added an offline fallback page with a small no-network jump game, similar in spirit to Chrome's offline game.
- Added browser speech reading and accessibility controls for larger text, high contrast and reduced motion.
- Google Calendar quick-add is available without OAuth. Full two-way Calendar sync still needs a Google OAuth client and server-side token handling.
- The app is prepared for Android App Actions and Alexa custom-skill integration, but those external developer-console/account-linking steps cannot be completed from the web app alone.

## Vercel Hobby function limit
Vercel Hobby permits up to 12 bundled Serverless Functions per deployment. This release keeps exactly 12 API functions by consolidating family-account actions into `api/subtenant.js` and Dad Lite actions into `api/dad-lite.js`.

## Google Calendar
For full API synchronization, create an OAuth 2.0 web client in Google Cloud and request only the Calendar scopes the product actually needs. The current Settings button uses Google Calendar's event-template URL, so users can add an event immediately without granting the app calendar access.

Official references:
- https://developers.google.com/workspace/calendar/api/overview
- https://developers.google.com/workspace/calendar/api/auth

## Google Assistant
Google Conversational Actions were sunset. For an Android application, the supported path for app voice actions is Google Assistant App Actions/Android capabilities. The web/PWA cannot simply register a private voice assistant skill by itself.

Official reference:
- https://developer.android.com/develop/devices/assistant/overview

## Alexa
A secure Alexa integration should use a custom skill plus OAuth 2.0 account linking before reading or changing private tenant data. The Alexa Developer Console supports custom interaction models and account linking.

Official references:
- https://developer.amazon.com/en-IN/docs/alexa/custom-skills/steps-to-build-a-custom-skill.html
- https://developer.amazon.com/docs/alexaplus/account-linking/steps-to-implement-account-linking.html
