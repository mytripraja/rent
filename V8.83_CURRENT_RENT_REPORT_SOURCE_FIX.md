# V8.83 — Current rent report source fix

For the current month, monthly reports and analytics now use the live `house.rentAmount` value when the house is occupied. Historical occupancy/rent history remains in use for past months. This addresses stale rent history overriding a corrected current rent in report calculations.

This update does not add a new standalone Rent Management page or navigation shortcut. The existing tenant edit form remains the way to change the rent amount; a dedicated, mobile-friendly rent workspace is a separate UI change.

Validation: source-level syntax and ZIP integrity checks only; no live Firestore test or full production build.
