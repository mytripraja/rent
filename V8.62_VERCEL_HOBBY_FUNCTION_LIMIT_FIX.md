# Rental Manager V8.62 — Vercel Hobby Function Limit Fix

## Production issue
Vercel Hobby rejected the V8.61 deployment with:

`No more than 12 Serverless Functions can be added to a Deployment on the Hobby plan.`

The previous deployment configuration accidentally exposed 13 API entrypoints even though the intended limit was 12.

## Fix
V8.62 reduces the deployed API entrypoint count to 11:

- `api/owner.js` combines create-owner and delete-owner.
- `api/media.js` combines get-agreement-url and get-signed-url.
- Existing public URL paths are preserved through Vercel rewrites.
- The original implementation files remain in the repository for safe reuse but are excluded as separate Vercel functions.

## Preserved URLs
- `/api/create-owner` -> `/api/owner?action=create`
- `/api/delete-owner` -> `/api/owner?action=delete`
- `/api/get-agreement-url` -> `/api/media?action=agreement`
- `/api/get-signed-url` -> `/api/media?action=signed`

## Security
No authorization logic was moved out of the original handlers. The router only selects the existing handler; the handlers continue to enforce their own authentication/authorization.

## Verification
- 11 Vercel API entrypoints are allow-listed in `.vercelignore`.
- Compatibility rewrites verified.
- JavaScript syntax verification performed for source/API files.
- No data migration or deletion.
