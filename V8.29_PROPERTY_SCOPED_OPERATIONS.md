# V8.29 — Property-Scoped Operations

- Maintenance requests now support house-batched reads for the active property.
- Booking approvals now load only houses belonging to the active property.
- Today's visitor overview now loads only the active property's houses.
- Parking slots now query by propertyId instead of reading the full collection and filtering locally.
- Existing data is preserved; legacy records remain available through the existing house/property compatibility logic.
- No composite index is required by these changes.
