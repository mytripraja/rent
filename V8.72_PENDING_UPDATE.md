# Rental Manager V8.72 — Pending Update Completion

## Included
- Rent approvals: removed duplicate initial loads, one house fetch per screen, cached short-lived approval requests, and property-scoped server query for normal properties.
- Announcement public links: linked announcements now appear on the public bilingual announcement page in addition to previous update chains.
- News Hub removed from tenant family-account permissions.
- Wi-Fi sharing: upgraded new listings to `wifi-share-v2` terms with clearer ISP, lawful-use, privacy and security conditions; legacy v1 listings remain readable.
- Critical rent correction security: settings UI for a separate critical-change password, email reset request, and device Face ID/fingerprint/passkey enrollment.
- Tamil translation: expanded property-management vocabulary and sentence patterns for rent increases, advance, household members, rooms, facilities, CCTV and Wi-Fi.
- Community: pinned-management-update filter and clearer mobile controls.

## Existing features preserved
- CCTV camera-to-house and house-to-camera mapping, covered places and privacy acknowledgement.
- Rent increase history, additional advance ledger, household member editing, fixtures/equipment history, announcement continuation/linking, bilingual public announcement pages, house room layout, and secure rent correction API.
- Firebase property access boundaries and existing legacy-data fallbacks.
