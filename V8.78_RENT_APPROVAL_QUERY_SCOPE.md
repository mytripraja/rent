# V8.78 — Rent Approval Query Scope

- Approval API now scopes the candidate house list to the requested property and caller access before querying rent payments.
- Queries rent payments in houseId batches (maximum 30 IDs) and filters waiting_approval locally.
- Avoids a collection-wide waiting_approval query and its broad read cost.
- Keeps server-side owner/property authorization and legacy `propertyId` fallback to `default`.
- No changes to the protected approved-payment correction flow.

Validation: API syntax check and ZIP integrity. A production build must still be confirmed by Vercel.
