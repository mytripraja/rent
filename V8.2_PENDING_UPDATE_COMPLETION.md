# V8.2 Pending-Update Completion

Implemented on top of V8.1:

- Resident-facing parcel notifications when a parcel is recorded for a house.
- Resident-facing visitor notifications when a gate visitor is recorded for a house.
- Maintenance completion can post the actual repair cost into the double-entry accounting ledger.
- Purchase orders can optionally increase an existing inventory item's quantity when the PO is marked received.
- Maintenance work orders now capture actual cost in the ERP form.
- Purchase orders now capture optional inventory item ID and received quantity.
- Package version advanced to 0.1.2.

Operational safety:
- External email, WhatsApp, SMS and AI providers remain opt-in and require provider credentials; no fake live connections or secrets were added.
- Cloud backup still requires BACKUP_BUCKET and the Firebase service account permission.
- Full Vite build remains environment-dependent here because dependency installation could not complete in the sandbox.

Recommended deployment checks:
1. npm ci
2. npm run build
3. firebase deploy --only firestore:rules
4. Configure REVOKE_CRON_SECRET and BACKUP_BUCKET.
5. Run the GitHub Actions workflows manually once and verify their HTTP responses.
