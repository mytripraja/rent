# V6.4 — Mobile, booking, parking and blueprint update

## Fixed
- Owner notification bell is visible in both light and dark themes.
- Notification panel uses a mobile-safe fixed layout and stays inside the viewport.
- Owner "Needs attention" cards no longer force horizontal overflow on small screens.
- Mobile bottom navigation labels no longer truncate unnecessarily.
- Vacant-house booking button keeps readable white text in dark mode.

## Parking
- Replaced prompt-based parking management with a visual parking map.
- Add slots by floor and vehicle type.
- Tap an available slot like selecting a movie seat.
- Assign a slot to an occupied house/resident and vehicle number.
- Release an assigned slot.
- Existing slots without positions receive a safe automatic layout.

## Common-area booking
- Replaced free-text time entry with selectable time slots.
- Tenant booking reads only that tenant's own booking records.
- Booking creation is tied to the authenticated tenant and their house.
- Firestore rules prevent tenants from reading other houses' booking records.

## Blueprints
- Added owner Blueprint tool in More Tools.
- Create a whole-property/apartment plan or a plan for each house.
- Add multiple floors.
- Add rooms and apartment units.
- Add Entry, Stairs, Lift, Parking and Electrical features.
- Drag blocks visually on a grid and edit position/size/name.
- Print the blueprint to PDF using the browser print dialog.
- Owner chooses whether a house blueprint is visible to its tenant.
- Tenant sees a read-only blueprint only after the owner enables visibility.
- Added Firestore rules for house and property blueprints.

## Verification
- JavaScript service syntax checks passed.
- Firestore rules delimiter balance checked.
- Full Vite build could not be completed because npm dependency installation timed out in the build environment.
