# Rental Manager V8.0 — Advanced Operations ERP

Added an optional Advanced Operations ERP hub for the existing local-apartment workflow.

## Added modules
- Future Society / Building / Floor / Unit hierarchy (optional expansion mode)
- Full accounting ledger: income, expenses, deposits, refunds, vendor/property transactions
- Maintenance work orders + preventive-maintenance-ready scheduling fields
- Purchase & inventory records with reorder levels and stock value
- Visitor/security gate events, incidents and vehicles
- Parcel/delivery register
- Digital document registry with expiry/renewal metadata
- Lease management: dates, rent, deposit, escalation, notice period
- Utility billing engine for electricity, water, gas, generator, solar and custom utilities
- Owner/investor portal records
- Advanced operational analytics
- Privacy-first local AI assistant foundation
- Communication records and audience/channel tracking
- Audit/security visibility using the existing activity log
- Backup/disaster-recovery export package and backup-plan records
- API/integration registry with server-side secret-reference guidance

## Local-apartment design
The new hierarchy is intentionally optional. A single apartment can continue using the existing property switcher and house workflow without enabling a society/building hierarchy.

## Security
The new Firestore collections are owner-only for now. Records carry `propertyId` so the architecture is ready for stricter server-enforced property ACLs later.

## Important limitation
The local AI assistant is a privacy-first rule-based assistant, not a hosted LLM. The API/integration registry is a configuration layer; it does not store provider secrets in Firestore. Automated cloud disaster recovery still requires a server-side scheduler/export target.
