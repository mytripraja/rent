# V8.70 — Notice Manager crash fix

## Problem
The owner Notices page could crash with `Cannot read properties of undefined (reading 'includes')` for existing/legacy notice data or a new form state where `linkedNoticeIds` was not initialized. Older notices can also have missing/non-array `targetHouseIds`.

## Fix
- Initialize `linkedNoticeIds` in the notice form state.
- Restore linked notice IDs safely when continuing an existing notice.
- Guard target-house membership checks with `Array.isArray(...)`.
- Keep announcement linking, continuation chains, sharing, and property scoping intact.
- Do not alter existing notice records destructively.

## Verification
- No malformed `from ... from ...` imports found under `src`.
- Targeted NoticeManager invariants checked.
- Full Vite build could not be completed in this environment because the dependency install/build process timed out.
