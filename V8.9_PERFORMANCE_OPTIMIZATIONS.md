# V8.9 Performance Optimizations

- Added a small in-memory request cache with in-flight request deduplication.
- Apartment Operations now avoids duplicate house/operations reads during rapid navigation.
- Assignment view reuses the short-lived all-houses cache.
- Analytics results are cached for 30 seconds to avoid rebuilding the portfolio dataset on repeated opens.
- Rent reminder rules use a short-lived cache and are updated immediately after writes.
- Cache invalidation is triggered after apartment operations are saved/created.
- Package version: 0.1.8.

This is a client-side performance layer; Firestore security and server-side authorization remain authoritative.
