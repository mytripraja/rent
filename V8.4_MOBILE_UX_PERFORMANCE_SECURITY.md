# Rental Manager V8.4 — Mobile UX, apartment switching and settings fixes

- Removed hard page reload from apartment switching. OwnerDashboard remounts the active route on property-change events instead, avoiding the long app boot/loading screen.
- Added a visible New apartment action to the mobile More screen and the current-apartment banner.
- Added a current-apartment selector to App Settings when multiple apartments exist. Apartment name/address edits now update the selected property instead of the global default config.
- Rent reminder settings now load houses and rules for the selected apartment.
- More screen refreshes the current apartment label when apartment selection/creation changes.
- Preserved lazy loading for infrequent modules.
- Kept Wi-Fi query index workaround from V8.3.
- Bumped app version to 0.1.3.

## Validation

- Backend/service syntax check and ZIP integrity should be run before deployment.
- Vite production build must still be run in a networked environment with dependencies installed.
