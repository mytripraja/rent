# Rental Manager V8.5 — Apartment Persistence & App Resilience

## Fixes
- Fixed the multi-apartment persistence bug: cached appConfig now retains `properties`.
- New apartments remain visible after navigation and subsequent config reads.
- `addProperty()` and `updateProperty()` keep the in-memory cache synchronized.
- Apartment creation no longer depends on a hard browser reload.
- Owner Dashboard Refresh now emits an app refresh event instead of restarting the entire Firebase/Vite session.
- Added a global render-error recovery surface.
- Added an offline/online status indicator for mobile users.
- Preserved V8.4 lazy loading and apartment switching improvements.

## Important
Run `npm ci` followed by `npm run build` in CI/Vercel before production deployment.
