# V8.68 — Performance, CCTV Access Mapping, Wi-Fi Terms, Secure Rent Corrections, Announcement Linking

## Performance
- Rent approvals no longer download the entire `rentPayments` collection on every load.
- Approval loading and house loading run in parallel.
- The secure approval API uses property-scoped house IDs and single-field `houseId in (...)` queries to preserve index resilience.
- Existing property security remains server-derived.

## News Hub
- Removed the News Hub from owner and tenant navigation and removed its API endpoint/component.
- This removes the third-party/news-feed surface from the product rather than relying on feed/copyright permissions.

## Wi-Fi sharing
- Added explicit Wi-Fi sharing terms and ISP/plan authorization acknowledgement.
- Listings record the terms version, acceptance time and accepting UID.
- Passwords are still prohibited from listings.
- Firestore create rules require the acknowledgement for new offers.

## CCTV privacy and access mapping
- CCTV cameras can map multiple houses that are permitted to view a camera.
- Cameras can record multiple covered places such as gate, parking, staircase, corridor and common hall.
- Owner UI supports both directions: camera → permitted houses and house → mapped cameras.
- New cameras require acknowledgement of legitimate-use/privacy rules.
- CCTV property IDs are immutable during updates.
- Actual CCTV credentials remain outside Firestore; only a secure-vault reference is stored.

## Announcements
- Announcements can be linked to multiple related announcements independently of the Update/continuation chain.
- Links can be changed or completely disconnected later.
- Public announcement pages show related announcements and previous updates together.
- Bell notifications now carry the public announcement link, so opening a notice from the bell reaches the full English/Tamil detail page.
- Related links are server-validated to remain within the same property.

## Rent history and tenant profile
- Rent revisions now record from/to amounts and effective month in the house profile.
- Optional next planned increase month is stored for future reminder/countdown display.
- Tenant profile shows rent increase history and next planned increase countdown.
- Advance payments can be labelled as initial move-in advance or additional advance collected later.
- Household members can be added/removed after move-in from the house profile; age bands and gender/relationship details are recalculated and saved.
- Existing house fixture tracking remains available for later additions such as fans, lights and calling bells.

## Critical-change security
- Added a separate server-side critical change password for high-risk rent corrections.
- Passwords are stored only as salted server-side hashes.
- Reset uses a short-lived email code through the existing Resend configuration.
- Face/fingerprint/device passkey can be enabled in Settings and is required on this device for secure rent correction when enrolled.
- Approved rent corrections preserve an audit trail and reverse the original accounting journal; an optional replacement amount creates a new approved payment and matching journal.

## Legal/privacy copy
- Expanded Privacy/Terms/Data policy with Wi-Fi sharing and CCTV-specific rules.
- Product copy explicitly states that it is not a legal opinion or guarantee of compliance and should be reviewed for the actual property/business arrangement.
