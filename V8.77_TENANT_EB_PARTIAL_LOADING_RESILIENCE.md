# V8.77 — Tenant EB partial-loading resilience

## Changes
- Tenant EB bills, payment history, and physical meter history now load independently.
- A failed query no longer prevents successful EB datasets from rendering.
- Partial-load errors are reported without clearing previously available state.
- EB bill share lookup safely handles malformed or legacy bill documents with missing `shares`.
- No Firestore rules or property-access boundaries were changed.

## Verification
- Source-level checks and ZIP integrity are performed for this release. A production Vite build is only reported if dependencies are available and the build succeeds.
