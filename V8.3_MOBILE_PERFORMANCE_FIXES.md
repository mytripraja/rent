# Rental Manager V8.3 — Mobile UX, Apartment Creation & Performance Fixes

## Verified from user-provided mobile video
- Settings modal was too long on mobile and required excessive scrolling.
- Owner header duplicated/truncated the account/app information and did not make the active apartment prominent.
- Creating an apartment caused a full page reload and a long loading screen.
- Apartment Operations loaded all-house assignments plus motors/tanks/problems/CCTV in the initial request, creating unnecessary Firestore reads.
- Neighbour Wi-Fi showed a Firestore composite-index error because `ownerUid + createdAt` was queried together.
- More Tools eagerly imported every secondary module, increasing the cost of opening the More screen.

## V8.3 changes
- Settings redesigned as a mobile full-screen panel with tabs: General, Notifications, Security, Accessibility, Voice, Calendar.
- Settings content is rendered only for the active tab.
- Mobile owner header now prioritizes the current apartment switcher and keeps account information compact.
- Apartment switcher can open even with one apartment and includes a direct **+ New apartment** action.
- More Tools now has a visible **Create New Apartment** item.
- Apartment creation no longer calls `window.location.reload()`; the new apartment becomes active immediately and the header updates through a local event.
- Apartment Operations initial load is reduced to apartment operations + current houses. Problems/CCTV and house-assignment data are loaded only when needed.
- More Tools secondary modules are lazy-loaded individually.
- Wi-Fi interest listing no longer requires a composite Firestore index; results are sorted client-side.
- Added a short in-memory `appConfig` cache to reduce repeated configuration reads while still invalidating immediately after configuration writes.

## Validation
- User-provided video manually reviewed for approximately 175 seconds.
- Backend/service syntax checks can be run with Node for `.js` files.
- Full Vite production build remains environment-limited if dependency installation cannot complete.
