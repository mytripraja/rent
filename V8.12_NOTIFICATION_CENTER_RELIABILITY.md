# Rental Manager V8.12 — Notification Center Reliability

## Changes
- Added the notification bell to Owner and Tenant headers.
- Mobile notification center expands within the viewport instead of clipping off-screen.
- Removed the Firestore `recipientId + orderBy(createdAt)` composite-index dependency from notification reads/subscriptions.
- Notifications are sorted by `createdAt` client-side after the property/user filter.
- Keeps notification preferences and read/unread behavior unchanged.

## Why
This reduces a common source of `The query requires an index` failures and makes notifications available without opening Settings.

## Validation
- Source edits completed.
- Full Vite build not claimed because dependencies are not installed in the working environment.
