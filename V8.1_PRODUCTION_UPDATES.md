# V8.1 Production & Security Updates

Implemented on top of V8.0:

- Server-enforced property ACLs for the new ERP collections using `users/{uid}.propertyAccess`.
- Property-scoped Firestore queries for ERP records and apartment operational issues/CCTV records.
- Double-entry accounting journal service: every new journal creates equal debit and credit lines.
- Approved rent payments automatically create a rental-income accounting journal entry when the house has a propertyId.
- Preventive maintenance scheduler now creates work orders and sends tenant maintenance notifications for occupied houses.
- Daily/15-minute operations notification sweep for document expiry, lease expiry and low inventory alerts with deduplication.
- Communication messages can create in-app notifications for residents in the active apartment or selected house.
- Property-scoped disaster backup export from the UI.
- Server-side automated backup job to a configured Google Cloud Storage bucket (`BACKUP_BUCKET`).
- Dedicated daily GitHub Actions backup workflow; it is intentionally separate from the 15-minute tenant/remainder scheduler.
- Advanced analytics now includes live occupancy, monthly rent potential, average rent and deposit totals.
- Local AI assistant now answers vacancy, occupancy, rent, maintenance, inventory, lease-expiry and utility questions from active-property data.
- Utility billing form calculates consumption and amount from reading/rate/fixed-charge values.
- Module search and loading status added to the Operations ERP hub.
- Audit records are written for ERP create/delete operations.

Important deployment configuration:

1. Keep `REVOKE_CRON_SECRET` configured in GitHub/Vercel as before.
2. Configure `BACKUP_BUCKET` with a private Google Cloud Storage bucket name.
3. Ensure the Firebase service-account identity has permission to create objects in that bucket.
4. Deploy Firestore rules from `firestore.rules`.
5. Run a clean `npm ci` and `npm run build` before production deployment.
