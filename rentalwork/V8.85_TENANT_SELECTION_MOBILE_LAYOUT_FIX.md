# V8.85 — Tenant selection and mobile layout fixes

- Added multi-house selection to Settings > Rent tracking start month, including Select all occupied and Clear selection.
- Retained single-house selection.
- Save applies the selected month to each selected house with confirmation; historical notes/payments are not deleted.
- Made Tenant Profile Communication Log fields responsive on narrow screens.
- Added global mobile overflow safeguards and safe-area-aware dialog padding.

## Important
The start month is stored per house. This UI change does not by itself alter legacy rent-due calculation logic. Test in staging before deployment.
