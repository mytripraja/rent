# Rental Manager V8.50 — Audit Log Property Privacy

## Changes
- Security audit logs are now admin-only because they contain account/identity metadata.
- Operational activity logs are property-scoped for restricted co-owners.
- New activity entries always carry `propertyId`.
- Activity Log UI queries the active property instead of loading the global activity stream.
- Activity log updates cannot move an entry between properties.
- Legacy activity entries without `propertyId` remain available to admin/unrestricted legacy owners but are not exposed to restricted co-owners.
- Rent approval/rejection, house booking/vacating, notices, and advanced ERP activity logging now attach the relevant property.
