# Rental Manager V6.8

### User-facing fixes
- Refreshing `/owner`, `/tenant`, and nested React Router URLs no longer falls into Vercel's 404 page when deployed with the new SPA rewrite.
- Removed the persistent welcome/onboarding `?` header button.
- Desktop tenant workspace now uses the full available width instead of a narrow mobile-like column.
- Accessibility settings now include larger text, high contrast, reduced motion, strong focus outlines, screen-reader/keyboard instructions, current-page speech, stop/pause reading, and browser voice navigation.
- Voice navigation supports English and Tamil examples for common pages.
- Google Assistant and Alexa setup/linking cards are visible inside Settings.
- Added a server-side three-attempt password guard with a 15-minute temporary lock and IP rate limiting.

### Security hardening
- Added Vercel security headers.
- Added optional Firebase App Check / reCAPTCHA Enterprise support.
- Added server-side App Check verification switch (`FIREBASE_APPCHECK_ENFORCED=true`).
- Tightened Firestore tenant permission updates.
- Added production security configuration documentation.

### Voice integration note
Google Assistant account linking requires an Android app plus an OAuth 2.0 authorization service. Alexa account linking requires a published skill plus OAuth 2.0 account linking. The UI now exposes these integration points without falsely claiming that an account is connected.

### Verification
- API/server JavaScript syntax checked with Node.
- Changed JSX files parsed successfully with the installed TypeScript transpiler.
- Full `npm ci` / Vite production build was not completed in this environment because dependency installation timed out. Do not treat this ZIP as locally build-certified until Vercel/CI runs `npm ci && npm run build`.
