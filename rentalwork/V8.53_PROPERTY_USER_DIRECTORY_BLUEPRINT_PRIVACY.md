# Rental Manager V8.53 — Property User, Directory & Blueprint Privacy

## Security fixes
- Restricted co-owners can no longer read arbitrary user profiles through the `/users` collection. Owner reads of tenant profiles are now limited to tenants whose house belongs to an assigned property; admins and legacy unrestricted owners retain their existing management access.
- The neighbor directory is now property-scoped for owner accounts. Restricted co-owners cannot enumerate another property's directory entries.
- Tenant blueprint reads now honor the existing `blueprint` tenant permission for both house and property blueprints.
- Owner house-blueprint reads are property-scoped through the house's property access boundary.

## Compatibility
- Self-profile reads remain allowed.
- Admin and legacy unrestricted owner behavior is preserved.
- Legacy directory records without `propertyId` remain available to admins/unrestricted owners through the existing fallback behavior, but are not exposed to restricted co-owners.
- No changes were made to the intentionally global community calendar or Wi-Fi sharing collections.
