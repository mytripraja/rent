# V8.83 update notes

## Included
- Removed the always-visible orange dot from the Rent approvals sidebar item. It was hard-coded and could falsely suggest pending approvals.
- Expanded Apartment Operations → Problem History to capture symptoms, root cause, action taken, temporary solution, permanent solution/prevention, and troubleshooting notes.
- Persisted the new maintenance fields in property issue records while retaining existing fields and old records.

## Important follow-up
- The rent-history start-month correction should be implemented only after tracing all rent due/balance calculations and payment/journal flows. A settings-only cutoff that does not affect every calculation would be misleading and could alter balances incorrectly. This update does not yet add that cutoff feature.
- Verify the build and Firestore rules in the project's normal development environment before deploying.
