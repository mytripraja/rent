# Rental Manager V8.41 — Tenant Creation Atomic Rollback

- Hardened `/api/create-tenant` against partial tenant creation.
- Customer linking/creation and the tenant `users` document are now committed in one Firestore transaction.
- If any Firestore step fails after Firebase Auth creates the tenant identity, the new Auth user is deleted automatically.
- Existing customer reuse by Aadhaar is preserved and now participates in the same atomic Firestore commit.
- Property access enforcement and the password-separation workflow remain unchanged.
- Existing tenant, house, customer, payment, bill, and property data are not migrated or deleted.
