# Rental Manager V6.5 — Calendar, Weather & House Details

## Calendar
- Added India Calendar & Panchang for owners and tenants.
- English month calendar with Tamil month/day reference.
- Festival dataset covering major Hindu, Muslim, Christian, Sikh, Jain, Buddhist, Tamil, regional, national and other Indian observances for 2026–2027.
- Daily Nalla Neram, Rahu Kalam and Yamagandam reference times.
- Owner/shared functions continue to appear with personal calendar notes.
- Tenants can add personal/family/payment/maintenance/function reminders without changing owner events.
- Personal notes are restricted by Firestore rules to their authenticated account.

## Weather
- Added current weather plus 7-day forecast.
- Search and switch cities/places inside the calendar.
- Uses Open-Meteo's public forecast/geocoding endpoints; no API key is stored in the app.

## Festival greetings
- Replaced the 3-item greeting list with a searchable festival catalogue.
- Added tradition filters and Tamil + English greeting templates.

## House profile
- Added owner-maintained room colour records with hex colour codes.
- Added provided-item inventory for lights, fans, calling bells and other fittings.
- Added owner notes for repainting/repair details.

## Security / compatibility
- Added `calendarNotes` rules for per-user private calendar entries.
- Calendar note retrieval avoids a composite Firestore index by filtering the user's notes client-side after a user-scoped query.
- Existing owner/tenant blueprint, parking and Dad Lite boundaries are retained.
