# Rental Manager V8.74 — EB Transparency, Meter History & Search

## Completed

- Tenant EB bills now show the bill cycle, tenant share, payment due date, official bill consumption units when recorded, previous/current government meter reading, and government reading date/time. Shared-meter amounts are explicitly described as the tenant share rather than falsely presenting a shared allocation as individual unit consumption.
- Added an `ebMeterReadings` history register. Owners can record physical meter observations with reading, date, time and optional note. Tenants with EB/bills permission can see only their own house history.
- Added bulk meter entry for all occupied houses in one owner screen. Bulk writes use a Firestore batch; history queries are chunked with single-field `in` queries to avoid composite-index requirements.
- Added optional previous/current government reading fields when creating an EB bill cycle. Consumption is calculated only when the current reading is not lower than the previous reading.
- Added selectable global search modes: All, Tenant, EB number, Door number, Government door, Phone and House. Search remains local over the already property-scoped house list, so it does not add network queries for every keystroke.
- Preserved property-scoped Firebase security. Meter records require the owner to have access to the house property; tenants can read only their own house meter history.
- Existing rental approval performance and announcement/security work from V8.73 is preserved.
