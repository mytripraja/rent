# V8.33 — Property-Scoped Notices

- Owner Home active notices are now limited to the active property plus global notices.
- Notice Manager lists notices for the active property plus global notices.
- Tenant Notice Feed subscribes only to global notices and notices targeted to the tenant house.
- Avoids downloading notices targeted to unrelated apartments.
- Uses simple Firestore filters without adding a composite index.
- Existing notice records and global notices are preserved.
