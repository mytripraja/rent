# V8.75 — EB Meter Register Loading & Reliability Fix

## Changes
- Fixed the EB meter register so a temporary EB bill/history query failure does not blank the entire EB Bill screen.
- Meter rows are created for every occupied house even when no physical reading has been recorded yet.
- Current local date/time is prefilled for faster physical meter entry.
- Meter history is queried by active property first, then filtered by the visible house list, avoiding the previous large `houseId in [...]` query path.
- Kept a compatibility fallback for older meter records that may not have `propertyId`.
- Added separate, non-blocking error messages for bill-cycle loading and meter-history loading.
- Added Refresh beside Save readings.
- Added last-saved date visibility for each house.
- Preserved property-scoped Firestore security and single-field/index-resilient queries.

## Verification
- Plain JS/API syntax checked with `node --check`.
- Vite production build attempted after dependency installation.
