# Rental Manager V8.45 — Additional Security Hardening

## Changes

### Owner-account creation rollback
If Firebase Auth creates a new co-owner account but the Firestore `users/{uid}` profile cannot be created, the newly-created Auth account is deleted. This prevents an orphan login account and allows safe retry with the same email.

### Profile-photo path isolation
Profile uploads now use `profile-photos/{uid}`. The signing endpoint requires the requested UID to equal the authenticated caller's UID, preventing a signed upload from being created for another user's profile path.

Existing profile URLs remain unchanged until the user uploads a new image.
