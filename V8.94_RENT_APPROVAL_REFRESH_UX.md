# V8.94 — Rent approval refresh resilience

- Keep the current approval list visible while a post-action refresh runs, with a small updating indicator instead of returning to the initial loading state.
- Sequence refresh requests so a slower earlier response cannot overwrite a newer result.
- Await the post-approval/rejection refresh before releasing the action's busy state.
- Preserve the displayed queue if a background refresh fails and tell the owner it may be stale; initial-load failures still show retry.
- Clear a draft rejection reason when the rejection dialog is cancelled.

Validation: source-level checks and ZIP integrity. Full Vite build and live Firestore tests were not run in this environment.
