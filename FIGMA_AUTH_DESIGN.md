Rental Manager — Figma authentication design

The updated mobile sign-in screen is implemented in:
  src/modules/shared/LoginPage.jsx
  src/index.css

To view it locally, install the declared dependencies and start Vite:
  npm ci
  npm run dev

Then open http://localhost:5173/login. The root route may show the public welcome page first; that page is separate from the Figma authentication design.
