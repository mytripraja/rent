# V8.14 — Vercel Build Fix

Fixed the second JSX syntax error reported by Vercel in `src/modules/shared/UserSettingsModal.jsx`.

Vercel error:
`UserSettingsModal.jsx:208:17: ERROR: Unterminated regular expression`

Cause: an extra `</section>}` after the General settings conditional rendered the JSX parser state invalid.

Fix: removed the extra closing `</section>` and retained the conditional closing `}` for `settingsTab === 'general'`.

Version: 0.1.14

Validation note: the source correction was inspected locally. A full Vite build could not be executed in the container because the dependency installation timed out and no Vite binary was available afterward. Vercel should be used as the authoritative production build check.
