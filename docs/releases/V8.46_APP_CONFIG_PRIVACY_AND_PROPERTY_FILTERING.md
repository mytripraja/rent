# V8.46 — App Configuration Privacy & Property Filtering

## Changes
- Full `appConfig/general` Firestore reads are no longer available to ordinary signed-in users.
- Added `/api/app-config`, authenticated with Firebase ID tokens.
- Admin and unrestricted owners receive the full configuration needed by management screens.
- Restricted co-owners receive only their assigned property entries.
- Tenants receive only the property associated with their house.
- This prevents the complete multi-apartment list and owner configuration from being exposed through direct Firestore reads.
- Existing owner writes remain available; no configuration data is deleted or migrated.
- Client `getAppConfig()` now uses the filtered API and retains the existing cache/fallback behavior.
