# V8.83 Mobile ergonomics update

Changes in this package:
- Tenant rent hero now has a lightweight Framer Motion 3D flip between the current rent status and a rent breakdown. The breakdown uses the known base rent only and explicitly does not invent missing EB/water shares.
- Flip interactions call the existing haptic utility and respect the reduced-motion preference.
- Global CSS adds mobile touch/overscroll ergonomics and GPU-friendly transforms for the rent card.
- Removed the always-visible orange dot beside Rent approvals because the current code does not bind it to a verified pending-approval count.
- Added a logout control to the compact mobile owner header.

Not included in this patch: isometric blueprint mode, swipe-to-approve/reject actions, and draggable modal bottom sheets. These need further targeted implementation and interaction testing.

Validation: `npm run build` could not be completed in this environment because Vite is not installed in the extracted workspace and dependency installation timed out. Test in a development environment before deploying.
