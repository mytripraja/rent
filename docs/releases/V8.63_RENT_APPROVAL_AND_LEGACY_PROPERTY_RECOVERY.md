# V8.63 — Rent Approval Recovery & Legacy Property Visibility

## Fixes
- Rent approval queue now uses the authenticated server router to derive accessible houses and return only `waiting_approval` payments for the active property.
- Avoids Firestore client `in` queries being rejected by property-scoped security rules, which could make a real pending rent submission appear as an empty approval queue.
- Legacy property discovery now supplements the property registry from the already-secured owner-house API when an older apartment still has property-tagged houses but its registry entry is missing.
- Existing property names are preserved; recovered entries are minimal and editable.
- No cross-property rent records are returned.
- V8.62 Vercel Hobby function consolidation is preserved; no new API function file was added.

## Compatibility
- Firestore fallback remains for emulator/local deployments where the secure rental route is unavailable.
- No existing apartment, house, tenant, payment, or document records are deleted or migrated.
