# Rental Manager V8.64 — Household, Date, Calendar & Announcement UX

## Changes
- Prevent mouse-wheel scrolling over rent/advance/number fields from changing values; the field blurs on wheel.
- Booking now supports an explicit **Date is approximate** flag for move-in dates.
- Booking now captures optional household member details for up to 20 people: name, age, gender and relationship.
- Age bands are calculated and shown as: Baby (0–2), Kid (3–17), Adult (18–59), Senior Citizen (60–74), Super Senior Citizen (75+).
- Household details and the approximate-date flag are stored on the house and occupancy history.
- Vacating a house clears current household details without deleting historical records.
- House profile shows current household details and approximate move-in date marker.
- Payment Calendar redesigned with month navigation, Today control, house/tenant search, house filter, summary status cards, responsive desktop/mobile views and payment detail modal.
- Announcement editor now has a clear Show time option. When disabled, public/share outputs show dates without clock times while retaining stored timestamps.
- Public announcement date fields respect the Show time preference.
- Announcement image/PDF/text share output respects the same time preference.

## Data safety
No existing records are migrated or deleted. New fields are optional and legacy houses continue to work.
