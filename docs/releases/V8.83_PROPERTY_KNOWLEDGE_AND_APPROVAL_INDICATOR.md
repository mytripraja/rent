# V8.83 update notes

- Expanded apartment tank records with tank type, dimensions, depth, opening location/access notes, last-cleaned date, cleaning interval, contractor and notes. This supports recording septic-tank access and service details; unknown capacity can remain blank until verified.
- Expanded problem history with symptoms, root cause, action taken, temporary solution, permanent solution/prevention, follow-up date and future warning. New fields are persisted in Firestore and displayed in the history list.
- Removed the unconditional orange dot beside Rent approvals because it was displayed even when no pending approvals existed. A data-driven indicator should be added only after the approval queue's live pending count is exposed to the navigation component.

## Important
Rent-accounting start-month correction is not included in this patch. It requires a dedicated settings workflow plus updating every pending-rent calculation and the server-side/API calculations, with a preview and confirmation step so prior manual-note months are excluded without modifying actual payment/journal records. Do not treat this version as completing that feature.
