# Rental Manager V8.40 — Tenant Password Separation

- Tenant creation no longer accepts an owner-supplied password.
- `/api/create-tenant` creates the tenant identity without a password.
- Password setup remains a separate tenant-controlled workflow through the existing secure setup/reset endpoint.
- Removed the unused password argument from the client tenant-account service.
- Existing tenant records are preserved; no migration or deletion is required.
