# V8.61 — Tamil announcements, real file sharing, and deployed API routing

## Changes
- Added editable Tamil announcement fields for title, message, category, reason, and additional details.
- English input automatically creates a best-effort Tamil draft; the owner can edit it and regenerate it before saving.
- Saved Tamil fields with the notice so they remain available after reload.
- Public announcement links show English and Tamil together.
- Text sharing includes both languages.
- Image sharing renders English + Tamil into the actual PNG file.
- PDF sharing renders the same bilingual card into the actual PDF file, avoiding PDF Unicode-font limitations.
- Image/PDF share button now explicitly shares the actual file through the device share sheet when supported; otherwise the real file is saved locally.
- Consolidated public-notice, owner-houses, and owner-documents handlers into `api/rental.js` and added Vercel rewrites because `.vercelignore` previously excluded those individual API functions from deployment.
- Documents page now uses the deployed owner-house API directly, avoiding the client Firestore house query that was producing `Failed to load houses` in production.
- Preserved property access checks in the server-side house/document APIs.

## Translation note
The automatic Tamil text is intentionally an editable draft. It uses an offline property-announcement phrase/word dictionary so announcement content is not sent to an external translation provider. Manual correction remains available before saving.
