# Rental Manager V8.47 — App Config Write Boundary & Customer Privacy

## Security fixes
- Scoped `/api/app-config` responses no longer spread global owner/payment configuration to restricted owners or tenants.
- Direct Firestore writes to `appConfig/general` are now admin-only; configuration updates go through the authenticated server endpoint.
- Restricted co-owners can update only apartment records inside their assigned `propertyAccess` scope.
- Rent reminder rules are now served and updated through the authenticated server endpoint; restricted co-owners cannot enumerate or overwrite another property’s reminder schedules.
- Full customer records are owner-only because they can contain Aadhaar numbers and linked-house history.
- Tenant `advanceLedger` reads now follow Rent + Rent Details permission rather than the unrelated Bills permission.
