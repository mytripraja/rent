# V8.60 — Announcement sharing, API routing, and document recovery

- Fixed Vercel SPA rewrite so `/api/*` requests are not rewritten to `index.html`.
- Hardened public announcement loading against HTML responses and added a clear service error.
- Image/PDF announcement sharing now uses the file-capable native share API; unsupported browsers fall back to saving the actual file instead of silently sharing only text.
- WhatsApp and email buttons are explicitly text-sharing actions because their URL schemes cannot attach generated files from the browser.
- Added owner-secured `/api/owner-houses` fallback for house loading.
- Added owner-secured `/api/owner-documents` for property-scoped document metadata loading, avoiding fragile client-side `in` queries.
- Preserved property access boundaries and private Cloudinary document viewing.
- No existing houses, tenants, documents, announcements, or payments are deleted or migrated.
