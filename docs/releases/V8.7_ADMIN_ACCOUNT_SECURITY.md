# V8.7 — Admin Account Security

## Added
- Admin account security panel for owner/admin accounts.
- Suspend/re-enable owner accounts using Firebase Auth disabled state.
- Revoke all refresh tokens/sessions for a selected account.
- Send a server-generated password-reset email through Resend.
- Server-side audit entries for account suspension, re-enable, session revocation and password reset delivery.
- Admin user listing merges Firebase Auth state with the application profile.

## Email change
The V8.6 dual-OTP and admin-review email change workflow remains unchanged.

## Security
- These actions require an authenticated `admin` role.
- An administrator cannot disable their own account through this UI.
- Password-reset links are generated server-side; the Firebase/Resend credentials never reach the browser.
