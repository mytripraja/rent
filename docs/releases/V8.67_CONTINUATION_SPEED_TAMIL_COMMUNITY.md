# Rental Manager V8.67 — Announcement Continuations, Speed, Tamil & Community

## Announcement continuation
- An owner can continue an existing announcement from the Notice Manager.
- Each continuation stores `parentNoticeId`, `updateNumber`, and `continuationLabel`.
- The public announcement page shows the previous update chain when those parent announcements are still publicly shareable.
- Shared text/image/PDF output includes the update label.
- The existing property-scoped notice rules remain unchanged.

## Speed
- House lists are cached/deduplicated for 30 seconds per property.
- All-house lists are cached/deduplicated for 30 seconds.
- Cache is invalidated after house/property mutations.
- App configuration cache increased to 120 seconds; writes invalidate it immediately.
- Legacy apartment recovery runs once per app session instead of on every property lookup.
- Notice creation reuses the already-loaded house list instead of querying houses again.
- Notice Manager loads notices/templates in parallel after the house list is available.
- Community subscription is capped at 60 recent messages instead of 100.

## Tamil
- Expanded curated rental/property announcement phrase and sentence rules.
- Reduced unsafe generic word-by-word grammar substitutions that produced unnatural Tamil.
- Preserves house/unit identifiers and numbers.
- Tamil remains an editable draft; owners can manually correct every field.

## Community
- Responsive community board with search, All/Mine filter, message count, timestamps, character limit, Enter-to-send, and mobile-friendly composer.
- HTTPS links in community messages are clickable.
- Owners/admins can post an announcement link directly to Community from the share dialog.
- Tenant mobile home has a direct Community quick tile and Community tool tab.
- Existing Firestore community permissions remain unchanged.

## Verification
- JavaScript/API files modified in this release were syntax checked with Node where supported.
- A complete Vite production build could not be executed in the current working environment because the dependency installation was incomplete/time-limited. Do not represent this release as locally Vite-built; Vercel remains the production build check.
