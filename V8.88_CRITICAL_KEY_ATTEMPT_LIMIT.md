# V8.88 — Critical-key attempt limiting

- Added a per-owner failed-attempt counter shared by the critical-key settings verifier and secure rent-correction endpoint.
- Five consecutive incorrect attempts trigger a 15-minute lockout.
- Successful verification clears the failed-attempt state.
- Completing the email-confirmed key reset also clears any verification lockout.
- The counter and lockout checks are transaction-backed to avoid concurrent requests bypassing the threshold.
- Existing key hashes and salts are unchanged; no user records are migrated or removed.

Validation: `node --check api/rental.js` and ZIP integrity check. Live Firestore behavior, multi-instance load behavior, and full Vite build were not tested.
