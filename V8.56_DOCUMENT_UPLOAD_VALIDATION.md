# Rental Manager V8.56 — Document Upload Validation

## Changes
- Bumped application version to 0.1.56.
- Tenant document metadata remains limited to the tenant’s own records by the existing V8.55 security boundary.
- Firestore create validation now requires supported document types (`aadhaar` or `ration_card`) and expected metadata field types.
- Tenant document UI rejects unsupported file MIME types and files larger than 10 MB before upload.
- Existing property access, private Cloudinary document flow, and index-resilient tenant listing are preserved.

## Verification
- Plain JavaScript syntax checked with Node.
- ZIP integrity checked after packaging.
- Full Vite build was not run because Vite is not installed in the available environment.
