# V9.00 — Consistent related-announcement links

- Related announcement links are now maintained in both directions.
- Removing a relationship from one announcement also removes its reciprocal reference.
- Link changes run in a Firestore transaction and revalidate existence and same-property scope.
- Self-links and more than 20 requested links are rejected.
- Update-chain relationships remain separate from related-announcement links.

Validation: JavaScript syntax and ZIP integrity checks. Full build and live Firestore/concurrency tests were not run.
