# Rental Manager V6.7 — Mobile, Access, Accessibility & Integrations

This release addresses the latest production screenshots and requests.

## Fixed / added
- Two-wheeler parking slots now use a bike icon instead of a car icon; EV uses an EV icon.
- Parking slots support drag/reposition with Firestore-saved coordinates.
- Tenant mobile UI redesigned into focused Home / Rent / Bills / More tools sections.
- Mobile calendar now has a readable day-list view.
- Tenant blueprint is surfaced as a mobile quick tool and can use the shared property blueprint when the owner has shared it.
- Blueprint mobile canvas reduced and made responsive; rooms are keyboard-movable for owners.
- Simple/Dad Lite owner mode and tenant permissions update live from Firestore profile changes.
- Admin tenant access controls added to each tenant profile, including Rent & payment submission.
- Language choice is asked once on first login and saved to the user profile.
- Language controls and notification center moved into Settings.
- Settings is always reachable from the header.
- Accessibility controls: larger text, high contrast, reduced motion, browser speech reading, keyboard focus support.
- Animated loading screen added.
- Dedicated 404 page added.
- Offline navigation now opens an offline mini-game instead of the normal page when the network is unavailable.
- News endpoint is included in Vercel deployment and Google News India is added as a fallback common feed.
- Vercel Hobby function count is kept at exactly 12 by consolidating family accounts and Dad Lite APIs into two routers.
- Google Calendar quick-add is available from Settings.
- Voice integration groundwork and setup notes added for Android/Google Assistant App Actions and Alexa custom skill + account linking.

## Validation
- JavaScript syntax checks passed for API/server/service files.
- ZIP integrity is checked after packaging.
- Full Vite production build was not run in this environment because `npm ci` timed out; the earlier Vercel build had already reached `✓ built in 6.23s` before this release.
