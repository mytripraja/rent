# Rental Manager V8.52 — Service Contact Permission Hardening

## Change
The `serviceContacts` Firestore collection previously allowed any signed-in account to read the complete service-contact directory, even when that tenant account had the Service Contacts permission disabled.

V8.52 changes the read boundary to:
- Owners: allowed
- Tenants: allowed only when `tenantCan('serviceContacts')` is true
- Other signed-in accounts without that tenant permission: denied
- Writes remain owner-only

This preserves the existing tenant Service Contacts feature while making the Firestore rule match the application's permission model.

## Preserved
- Property security boundaries
- V8.51 Activity Log index-resilience changes
- Existing community calendar and Wi-Fi sharing behavior
- Legacy data compatibility
