# V8.17 Build Correction

Fixed the exact V8.16 build error shown by Vite in OwnerManager.jsx.

## Root cause
The three inline admin-security button handlers were missing the final `}` that closes the JSX `onClick={...}` expression after the async function body.

Affected actions:
- Suspend / Enable
- Revoke sessions
- Reset password

The broken ending was effectively `finally{setSecurityBusy('')}}} className=...` with one brace missing. It is now balanced before `className`.

Version: 0.1.17
