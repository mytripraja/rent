# V8.76 — Desktop startup and service-worker reliability

## Changes
- Versioned the service-worker cache so deployments do not continue using the previous app-shell cache.
- Navigation now requests the current HTML without using the browser HTTP cache and does not replace a valid online response with a stale cached document.
- Cached app assets are refreshed from the network when online; failed/missing chunks are not masked by stale cache entries. Offline fallback remains available.
- Added a lightweight startup screen and a delayed recovery message for cases where the app shell never mounts, instead of leaving an unexplained blank page.
- Bumped package version to 0.1.76.

## Scope and limitations
This is a reliability mitigation based on the available source and the reported desktop-only white screen. The supplied screenshot did not expose a definitive application exception, so this does not prove the original cause. It does not change authentication, Firestore rules, tenant data, or property access.
