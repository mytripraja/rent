# V8.39 — Tenant Creation and API Property Access

- Tenant creation no longer requires a password; email is optional.
- Owners create the tenant record first and can link email/send secure password setup later.
- Owner-facing subtenant APIs now enforce propertyAccess against the target house.
- Tenant login setup and tenant-contact APIs now verify the selected house belongs to an accessible property.
- Rent-agreement signed URLs now enforce owner property access.
- No application data is deleted or migrated.
