# V8.86 — Critical change password reset protection

- Reset codes are generated with a cryptographically secure random integer.
- Reset requests are limited to one per account per 60 seconds.
- Reset confirmation counts incorrect codes transactionally and locks the code after five failed attempts.
- Successful confirmation updates the key and consumes the reset code in the same transaction, preventing concurrent reuse.
- No migration or destructive changes are required; the new fields are additive.

Validation: JavaScript syntax and ZIP integrity checks only. No live email, Firestore, concurrency, or full Vite build test was performed.
