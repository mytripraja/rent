# V8.26 — Property-Scoped Rent Data Loading

## Changes
- Added a reusable `listRentPaymentsForHouses()` service helper.
- Bulk rent reads are now limited to the current apartment’s house IDs in chunks of 30, instead of downloading every `rentPayments` document.
- Updated Payment Calendar to use the property-scoped rent loader.
- Updated Tally Export and Google Sheets Export to export rent records for the currently selected apartment.
- Updated the owner data backup rent export to use the same house-scoped loader.
- Updated the monthly Email Report rent calculation to use the current apartment’s houses.
- Made the rent CSV backup fields CSV-safe when values contain commas, quotes, or line breaks.
- Kept legacy rent records intact; the change only limits which existing records are loaded by these screens.
